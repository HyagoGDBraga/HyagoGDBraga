## O que estou construindo

**Sistema de gestão hoteleira:** monólito modular em NestJS com Prisma e PostgreSQL, usando row-level locking pra evitar overbooking e já pensado pra multi-tenancy.

**Plataforma de match de vagas:** NestJS + TypeORM + RabbitMQ, com busca semântica via RAG (pgvector) pra conectar candidatos e oportunidades.

**Sistema de laudos técnicos para engenharia geotécnica:** pipeline HTML-to-PDF com WeasyPrint, sistema de design próprio e geração automática de sumário.
